# Changelog

## Unreleased

- Fixed the chatroom, room-user, and private-message action sheets rendering as a clipped bubble squeezed against the bottom of the screen: iOS 26 honors a popover anchor on a compact iPhone, so those widths now take the system's own full-width sheet and only regular widths anchor, through one shared helper.
- Reworked both conversation composers — chatrooms and private messages — into one growing multi-line field: Return inserts a line break, the send control is the only way to send, the field grows from one line to five (never past a third of the screen) before it scrolls, and it keeps a fixed corner radius, wider text insets, and a gap above the keyboard instead of the capsule whose round ends overran the text.
- Gave the private-message composer the chatroom's treatment: a field floating over the transcript instead of a filled bar, a circular filled send control, and a floating jump-to-latest control instead of a full composer row.
- Added drag-to-reply in chatrooms and private messages: a trailing drag on a message follows the finger, fades in a reply glyph, and quotes the message into the composer as `> {user} said: "{message}"` on release — with a blank line and the caret beneath, preserving any existing draft. There is no Reply button to press afterwards, and Reply is also the first action in every message action sheet and a VoiceOver custom action on every message row. Incoming messages no longer interrupt a drag in flight, and auto-following the newest message no longer cancels the gesture.
- Fixed conversations losing their newest message: sending now always returns to the message just sent, raising the keyboard keeps the transcript pinned to the latest message instead of leaving it stranded above the composer, and messages arriving while the keyboard is up scroll into view. Anchoring now measures self-sizing rows before it scrolls, so a long arriving message no longer lands half-hidden behind the composer.
- Fixed the keyboard being impossible to put away without sending: a tap anywhere on the conversation now dismisses it and restores the full message history. With the keyboard down, tapping a message still opens its actions.
- Enabled both send controls only for a reachable conversation with a non-empty draft, and returned focus to the composer after a send so the keyboard survives a conversation.
- Fixed the conversation send and jump-to-latest glyphs rendering as clipped slivers at accessibility text sizes.
- Added `ANIMASEEK_UI_ROOM` to the Debug Mock launch harness so one named chatroom can be opened directly for repeatable simulator inspection.
